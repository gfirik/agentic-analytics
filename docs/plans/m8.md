# M8 plan: Web lane (`packages/web`)

Specs: docs/specs/agent-and-verifier.md §3–§4; docs/specs/security.md §1, §3–§4.
Acceptance (ROADMAP M8):
- sanitizer tests show no private values ever reach queries;
- the SSRF tests block private IPs;
- a web-enabled run labels external claims.

## Tasks

1. **Sanitizer** (`sanitize.ts`).
   - Strips private names (phrases, with or without legal forms), private values, emails, phones, URLs and every number except years.
   - Tested with hand cases and a seeded property test (300 random queries mixing private and public terms).
2. **Address blocking** (`ip.ts`): IPv4 and IPv6 blocklists, including mapped, NAT64 and 6to4 embedded IPv4.
3. **Safe fetcher** (`fetch.ts`, a node:http(s) adapter).
   - URL checks: scheme, port, credentials, local names, literal private hosts, private query values.
   - Every resolved address is checked inside the socket lookup, so no rebinding window.
   - Manual re-checked redirects, a timeout, a size cap and text-only types.
   - Tested against a loopback test server for redirects, loops, size, type and time.
4. **Readable text** (`html.ts`): a tolerant tag scanner that drops scripts, navigation and hidden elements, where injections hide.
5. **SearXNG provider** (`searxng.ts`), and `webSearch` (sanitize → search → fetch → text, skipping failed results with reasons).
6. **Engine wiring**:
   - `privateTerms(ws)`;
   - `search_web` stores pages as external sources `W…` and extracts them through the quarantined extractor (marked `external`);
   - `compare_benchmark` (`parseQuotedRange` → `external_quote` facts → `benchmark_gap.v1`);
   - the WEB_CONTEXT stage;
   - web sources in the draft;
   - `aa run --web`;
   - a SearXNG compose service with JSON enabled.
7. **Tests**: web package unit tests; a web-enabled coffee job with a fake provider and pages (one hidden injection and one metadata URL); the web lane off.

## Risks

- **Real SearXNG and the internet are not always available.** The real check is a separate command, DEFERRED if the container can't start.
- **Private-term recall is heuristic.** Column labels decide which values count as names. The sanitizer also drops every non-year number, and the fetcher refuses URLs whose query string carries a private value.
