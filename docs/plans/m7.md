# M7 plan: Agent (`packages/agent`) and pipeline (`packages/core`)

Specs: docs/specs/agent-and-verifier.md §1–§6, §8–§9; docs/specs/security.md §2–§3; docs/ARCHITECTURE.md §2.
Acceptance (ROADMAP M7):
- an end-to-end coffee-roaster job with FakeModel produces a draft report with placeholders only;
- a manual run with a free model finds P1 and P2 (DEFERRED if no model is configured);
- resume after killing the process mid-job works.

## Tasks (in order)

1. **Analysis entry points for tools** (`packages/analysis/src/slice.ts`):
   - `drillDown` (contribution.v1 on one metric/period/dimension slice);
   - `scenarioFacts` (impact.v1 over existing facts);
   - `readFacts` and `loadAnalysis` (resume);
   - fact refs to existing facts, and a FactBook id offset, so new facts continue after the stored ones.
2. **Core** (`packages/core`):
   - structured logger;
   - event bus (validated, numbered, stored in `events`);
   - the pipeline runner, with checkpoints in `job_stages` (migration 4): completed stages are skipped; an interrupted stage has its facts deleted, is reset and re-run;
   - `runJob`: a job folder holding `input/`, `job.duckdb` and `report.draft.json`.
3. **Agent** (`packages/agent`):
   - prompts (`prompts/*.md`, typed `[[variables]]`, snapshot tests);
   - fact sheet;
   - quarantined extractor (strict schema, exact quotes, regex screen and quarantine);
   - fixed tools with a budget;
   - deterministic observed claims;
   - EXPLAIN (tool loop, then structured write-up, with checks on fact/extract ids and causal grades);
   - DECIDE (impact computed in code, ranking, drops);
   - headline;
   - draft assembly (schema + integrity valid, no numerals outside facts);
   - small-model mode.
4. **CLI** `aa run <paths>` / `aa run --resume <dir>` with the configured models.
5. **Tests**:
   - unit tests for each agent part;
   - a scripted coffee-roaster FakeModel (`packages/core/testing`);
   - the E2E draft test;
   - the kill-and-resume test (child process, SIGKILL during EXPLAIN);
   - a stage-failure resume test;
   - CLI tests.

## Risks

- Model-written text with numerals → Zod refinements reject it, and the structured-output retries feed the error back.
- Untrusted text reaching the planner → only extracts (quotes inside data delimiters) and fact labels reach it, never documents.
- Resume correctness → stages are idempotent: each re-run deletes its facts (from `first_fact`) and its own rows first. The test compares a resumed draft with an uninterrupted one.
