# M0 plan: Foundation

Branch: `m0/foundation`. Source: docs/ROADMAP.md M0, docs/ARCHITECTURE.md §5, docs/ENGINEERING.md §2/§4, docs/specs/interfaces.md §2 (`aa doctor`), docs/specs/models.md §3–4 (providers).

## Tasks (in order)

1. **Workspace skeleton.** `package.json` (packageManager pinned, scripts), `pnpm-workspace.yaml` (`packages/*`, `apps/*`, `evals/*`), `turbo.json`, `tsconfig.base.json` (strict, `noUncheckedIndexedAccess`, ESM/NodeNext), `biome.json`, `vitest.config.ts`.
2. **Empty packages with READMEs** (ARCHITECTURE §5): `packages/{schema,store,core,ingest,profile,metrics,analysis,retrieval,web,models,agent,verify,report}`, `apps/{server,cli,mcp,telegram,viewer,docs}`. Each has `package.json`, `tsconfig.json`, `src/index.ts`, `test/` (with `.gitkeep` until there are tests), `README.md` (purpose, public API, example, owning milestone). Internal-package pattern: `exports` points at `src/index.ts`, so no build step is needed for dev or tests.
3. **Schema-drift check.** `packages/schema` gets a JSON Schema registry (empty in M0, filled in M1), `scripts/schema-drift.ts` regenerates JSON Schema from Zod (`z.toJSONSchema`) and compares against committed `packages/schema/json/*.json`; `--write` updates them. Unit-tested on an in-memory registry: matching → no drift; changed/missing/extra file → drift reported.
4. **`store.duckdbVersion()`.** Opens an in-memory DuckDB instance via `@duckdb/node-api` and returns `SELECT version()`. Test asserts it returns a `v1.x` string.
5. **`aa doctor`** (`apps/cli`, citty). Checks Node (≥22), DuckDB version, Ollama (`GET {OLLAMA_BASE_URL}/api/tags`), openai-compatible endpoints whose key env var is set (`GET {base}/models`), SearXNG, Docling. Each check returns `{ name, status: ok|missing|error, detail, fix? }`. `fetch` and env are injected; tests use a stub fetch (no network). Always exits 0 when only optional services are unreachable; exits 1 only if Node or DuckDB fails. Root script `pnpm aa <cmd>`.
6. **`pnpm check`** = `biome check . && turbo run typecheck && vitest run && pnpm schema:drift`.
7. **CI** `.github/workflows/ci.yml`: PR + push to main, Node 22, `pnpm/action-setup`, setup-node pnpm cache, `pnpm i --frozen-lockfile`, `pnpm check`, then `pnpm aa doctor` as a smoke step.
8. **Repo files**: `LICENSE` (Apache-2.0), `.env.example` (already present; add `OPENAI_COMPATIBLE_*` only if needed), `.gitignore` (already present), `docker-compose.yml` with `engine` (default) and `searxng` (web), `docling` (docling), `ollama` (ollama) profiles; `docker/engine.Dockerfile`.
9. **Ledger**: STATE.md status, decisions, gaps.

## Tests

- `packages/schema/test/drift.test.ts`: drift detection on in-memory registries.
- `packages/store/test/version.test.ts`: DuckDB version string.
- `apps/cli/test/doctor.test.ts`: Node version parsing, all-unreachable case (status `missing`, exit code 0), Ollama reachable with models listed, openai-compatible skipped without key, DuckDB failure → exit 1. Stub fetch only.

## Acceptance → proof

| Criterion | Proof |
|---|---|
| `pnpm i && pnpm check` passes on a clean clone | QA: `git clone` into a temp dir, `pnpm i --frozen-lockfile && pnpm check` |
| CI green on first PR | `gh pr checks` on the M0 PR |
| `aa doctor` prints Node + DuckDB versions and provider reachability | `pnpm aa doctor` output in the PR (no Ollama on this machine → reported as not reachable, which is acceptable) |

## Risks

- **Brand-new major versions** (TypeScript 7 native, Vitest 5, pnpm 12). If one misbehaves, pin the previous major and record the decision.
- **DuckDB native binding** under pnpm's build-script policy: `@duckdb/node-api` ships prebuilt platform packages, so no build script should be needed; verify on CI (ubuntu-latest).
- **TS execution of the CLI** without a build step: use `tsx` in the bin shim. A real bundle for Docker comes with M10/M12.
