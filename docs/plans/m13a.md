# M13a plan: Quality and free providers (human gate)

## Tasks, in order

1. **Presets** (packages/models/src/config.ts):
   - Remove `github-models` (retired 2026-07-30) and its doctor probe.
   - Add `nvidia-nim` (`https://integrate.api.nvidia.com/v1`, `NVIDIA_API_KEY`), `google-ai-studio` (`https://generativelanguage.googleapis.com/v1beta/openai`, `GEMINI_API_KEY`), `sambanova` (`https://api.sambanova.ai/v1`, `SAMBANOVA_API_KEY`) and `cloudflare` (`https://api.cloudflare.com/client/v4/accounts/${CLOUDFLARE_ACCOUNT_ID}/ai/v1`, `CLOUDFLARE_API_TOKEN`).
   - Base URLs may reference env vars.
2. **Router** (packages/models). A role may list routes (`openai-compatible:nvidia-nim:openai/gpt-oss-120b|openai-compatible:groq:openai/gpt-oss-120b`). Every route must name the same model; the config is refused otherwise.
   - Per route: a token bucket from `x-ratelimit-remaining-*` / `x-ratelimit-reset-*` and `retry-after`.
   - On a 429 or an empty bucket: the next route with the **same model**, immediately. If none has capacity, wait as long as the soonest route asks (within a cap). Past the cap, stop with `RATE_LIMITED`, naming every route and when it frees up.
3. **Calls.** Tool calls and structured output stay separate calls; a transport test enforces it (no `response_format` in a tool loop, no `tools` in an object call).
4. **Cache.** HTTP-level: key = sha256(url, request body), which holds the model, messages and params. Only 200 responses are stored. Tools still run locally on replay, so cached runs produce the same facts. It is on for `aa eval` (`evals/.cache/`, gitignored) and opt-in elsewhere (`AA_MODEL_CACHE`).
5. **Call log.** Every call reports `{ role, provider, model, route, cached, status, tokens, ms }` to a hook. The CLI logs it, and eval results record the per-route call counts and the models actually used.
6. **Engine gaps:**
   - Seasonal: a change is seasonal, not material, when the same calendar month in another year deviates the same way.
   - Member changes: the strongest member-level change gets an EXPLAIN slot after the family slots.
   - Drafting: code adds the profiled grouping columns (customer, channel, product, …) to sum and count metrics over the same table, and the prompt prefers transaction tables over summary sheets.
7. **Reruns.** Smoke, then the full suite, with NIM (GLM-5.3 or Kimi K3 planner) plus Groq, cached and logged. Report the numbers.

## Risks

- **Free-tier quotas.** Mitigated by the cache, the router and small-model mode; quota stops are reported, not hidden.
- **Changing the engine to hit the bars could overfit the generator.** Every change must be principled and spec-backed, keep the coffee goldens, and be judged on all 30 datasets.
