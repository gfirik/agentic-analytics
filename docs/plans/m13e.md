# M13e plan: real public data evals

Maintainer's request: add a "real data" tier next to the synthetic suite. Download (never commit) UCI Online Retail II and one more openly licensed sales dataset, with a fetch script that verifies checksums; run the engine; check that it doesn't crash, reports the data-quality issues (cancellations, missing customer IDs, negative quantities) and finds known patterns (the Nov–Dec peak); write the checks as small answer files; publish the results in RESULTS.md, the README and the docs site.

## Tasks, in order

1. Pick the second dataset and verify its licence on the publisher's own page. Rejected candidates and why go in evals/real/DATASETS.md.
2. `evals/real` package: a manifest with URLs, licences, credits and the SHA-256 of the download, the archive entry and the derived file; `fetchDataset` with injected fetch and file access; pure derivations.
3. Run the engine on the raw and derived files with the baseline model. Fix what breaks, with hand-computed tests, or record the gap.
4. Answer files: ground-truth SQL (DuckDB over the derived file) and checks that read only report.json.
5. Runner: `aa eval --suite real`, `bun run eval:real`, results JSON and the RESULTS.md section; README table generated by `readme:assets` and checked by `readme:check`; docs page section.
6. Tests: fetch and checksum verification without network, the derivations, scoring of every check kind, the RESULTS.md section, an end-to-end job on a small invoice file, and a re-run that must reproduce the committed results when the data is present (skipped in CI).
7. Docs: EVALS.md, the package README, DATASETS.md, specs touched by engine fixes, STATE.md.

## Risks

- The full Online Retail II workbook is 45 MB and over 1M rows: memory on this machine, and the engine's ZIP limit. Derive a deterministic sample if the engine refuses it.
- Government statistics publish CSVs that change monthly. Use a per-release URL so the checksum holds.
- Checks must not be tuned to pass. A failing check stays and goes to Known gaps.
- No real-model runs: the Groq quota is in use. Real-model runs are DEFERRED with the exact command.
