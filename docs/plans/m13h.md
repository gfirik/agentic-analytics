# M13h plan: real-run fixes

Fixes found by running the engine on real models and real hardware after M13a/M13e. There is no new feature
milestone in ROADMAP.md: each item is a small PR (`m13h/<task>`) that closes a failure seen in a real run, with a test
that reproduces it first. Status and PR links are kept in the M13h row of `docs/progress/STATE.md`.

## Tasks (in order of landing)

1. **Router cache under rate limits** (#25, merged): when every route is rate-limited, the router serves an answer
   already in the response cache instead of waiting or failing — models §5.
2. **Metric alias** (#26): construction_supplier-v1 failed at MEASURE with DuckDB's `duplicate alias "m1"`. The cause
   was a drafted ratio of a metric to itself (`FROM m1 FULL JOIN m1`). Fixes:
   - validation rejects self-ratios and derived `x / x`, with an "(always 1)" reason;
   - every join side gets a unique alias;
   - every job saves `metrics.drafted.json`, and `--keep-reports` keeps it for evals.

   Specs: metric-layer §2.3, §2.6 and §4.
3. **DECIDE budget** (#28): the small-model DECIDE request stays under a 6.5k-token input budget, so free tiers with a
   7k tokens-per-minute cap (printing_shop-v1) can finish — agent-and-verifier §8.
4. **Partial results and a daily runner**: a full-suite run on a free tier keeps per-dataset results as they finish
   and resumes the next day, so a quota stop never loses finished jobs — EVALS §3.
5. **Kaggle notebook** (#27): runs the full suite on vLLM (Qwen3.8-27B AWQ on 2×T4) for a real-model full-suite
   result without a paid API — EVALS §3.
6. **Resource limits** (#29): heavy jobs (gate, full test runs, builds, evals, Playwright) run one at a time, with
   lower test parallelism, because the dev laptop runs out of RAM under parallel agents — AGENTS §9.

## Risks

- PRs touch STATE.md in parallel: each one merges origin/main first and adds its decision lines to the shared M13h
  block, never rewriting another PR's lines.
- Real-model checks need quota or a GPU: they are DEFERRED with the exact command when not available (AGENTS §2.9).
- Recorded docs data (learn.json, pipeline.json) drifts when compiled SQL or wording changes: regenerate and commit it
  in the same PR.
