# M13c plan: README pipeline GIF

Replace the static "How it works" diagram in the README with an animated GIF of the pipeline, recorded from the same animation the docs `<Pipeline />` island plays.

## Tasks, in order

1. **Data from a real run.** `apps/docs/scripts/pipeline-data.ts` runs the engine once on `examples/coffee-roaster` (scripted planner, offline web fixture, hash embedder). It extracts the stage order from the event log, the headline facts, the driver, the cited quotes and the top action from the verified report, and V1–V8 counts from the `verification` table. It writes `docs/assets/readme/pipeline.json`.
2. **One scene.** `apps/docs/src/components/pipeline-scene.ts` defines `sceneSvg(data, t)`, a pure function that returns the frame at time t. It runs on a 640×480 canvas, loops in ≤ 15 s, and colors come from CSS tokens (light and dark).
3. **Recorder.** `scripts/readme-assets/pipeline-gif.ts` takes Playwright screenshots frame by frame and builds a palette GIF per theme with ffmpeg, plus a still PNG. It writes `pipeline-gif.json` with the hash of its inputs.
4. **README.** A generated `<picture>` block (`diagram:pipeline-gif`) contains the GIFs, the PNG for reduced motion, and the alt text, all drawn from the data.
5. **Docs island.** `<Pipeline />` plays the scene. Under reduced motion it shows the finished frame and step buttons.
6. **Checks.**
   - `readme:check`: the files exist, each is ≤ 3 MB, ≤ 15 s and ≥ 720 px, and the input hash matches.
   - Vitest: the data holds −17.9%, wholesale, the hotel email and the fact ids, and it matches a fresh run.
   - Browser job: the `<picture>` serves the right variant, and text stays inside the canvas.

## Risks

- **GIF size and legibility at 360 px.** Mitigation: flat colors, a 48-color palette, no dithering, rectangle diffs, and large type.
- **Floating-point noise in DuckDB sums across machines.** Mitigation: the drift test compares numbers to 9 significant digits.
- **Re-recording needs Chrome and ffmpeg locally.** CI can't record, so it checks the input hash instead.
