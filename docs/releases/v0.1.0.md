**agentic-analytics v0.1.0: files in, a verified and cited report out.**

Give it a business's spreadsheets, CSV exports, PDFs, Word documents and emails. It returns what changed, why, where the data is wrong, and what to do next.

- Every number is computed by SQL in DuckDB and recomputed by a verifier before the report ships.
- Every claim links to the row, cell, page or URL it came from.
- It runs locally at $0 with Ollama or a free endpoint.

## Try it

```bash
git clone https://github.com/gfirik/agentic-analytics && cd agentic-analytics && bun install
ollama pull qwen3.5:9b        # or set GROQ_API_KEY and PLANNER_MODEL in .env (see the Quickstart)
bun run aa analyze examples/coffee-roaster --yes --currency USD --today 2026-07-01 --small-model --embedder hash --open
```

Or with Docker: `docker pull ghcr.io/gfirik/agentic-analytics:0.1.0`, or `docker compose up` for the API, the viewer and MCP on 127.0.0.1:8080.

## Honest status

- The engine, the verifier and all four doors (CLI, HTTP API, MCP, Telegram) work end to end. The CI suite has 500+ tests and a 23-fixture prompt-injection suite.
- The eval bars are **not** met yet. On the smoke suite no free model we tried passes them: the one that completed every job found the key event twice, with the wrong driver. The scripted baseline that checks the harness is reported separately and is not a measure of model quality.
- Full results and known gaps are in [evals/RESULTS.md](https://github.com/gfirik/agentic-analytics/blob/main/evals/RESULTS.md) and [docs/progress/STATE.md](https://github.com/gfirik/agentic-analytics/blob/main/docs/progress/STATE.md).
