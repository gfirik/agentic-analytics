title: Contributing
description: How to propose a change.
---

See [CONTRIBUTING.md](https://github.com/gfirik/agentic-analytics/blob/main/CONTRIBUTING.md). In short: work on a branch, use Conventional Commits, run `bun run check` (lint, types, tests, schema and README drift), and open a pull request that says which behaviour changed and how it was tested. Every number in the engine comes from SQL or a deterministic function with a hand-computed test — that rule is not negotiable.
