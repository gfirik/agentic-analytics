## 2. Add the documents

Put the price list (PDF), the hotel's email (EML) and the operations notes (DOCX) next to the workbook. That is just the whole example folder:

```bash title="Terminal"
AA_DEMO_MODEL=scripted bun run aa analyze examples/coffee-roaster --yes --embedder hash --today 2026-07-01 --currency USD
```

The email moved one claim to `document_supported`: the hotel wrote that it paused its standing order *after the new price list*, and the report quotes it exactly, with the file and the character span. The price list supports a weaker claim, `correlated`: prices went up shortly before the drop. The numbers did not change at all; they never come from documents.

## 3. What counts as evidence

- **Formats:** PDF (with a text layer), Word (DOCX), email (EML, headers included), Markdown and plain text. Scanned PDFs can go through an optional Docling container.
- **Put them in the same folder** (or list them on the command line) as the data. Every file of a job is indexed.
- **They are untrusted.** A document can't give instructions: it is [screened](../../stages/security/), and only the quarantined extractor reads it. A document that tries is quarantined and listed in the report.
- **Grades are earned.** A cause needs a quote that says so; the verifier checks the quote exists in the file and that causal wording has a document behind it.

## What you learned

- Without documents the report describes; with them it can explain, and says how strongly.
- Every causal claim cites an exact quote you can open.
- Documents add explanations, never numbers.
