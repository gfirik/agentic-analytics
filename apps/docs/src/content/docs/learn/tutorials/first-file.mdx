**Tutorial 1 of 5.** About ten minutes. No model, no API key, no internet after installing.

You will run the engine on the example files, read what it found, and check one number all the way down to the spreadsheet rows.

## 1. Install

You need [Bun](https://bun.sh) (the package manager) and Node 22. From a clone of the repository:

```bash title="Terminal"
bun install
bun run aa doctor
```

`aa doctor` lists what is configured. It will say no model is reachable, which is fine for this tutorial.

## 2. Run the job

```bash title="Terminal"
AA_DEMO_MODEL=scripted bun run aa analyze examples/coffee-roaster --yes --embedder hash --today 2026-07-01 --currency USD
```

What the parts mean:

- `AA_DEMO_MODEL=scripted` replaces the language model with the **scripted planner**, a replay of a model's decisions for this example. Leave it out once you have a model configured.
- `examples/coffee-roaster` is a folder; every file in it goes in.
- `--yes` keeps the drafted metric definitions as assumptions instead of asking you (the [next tutorial](../confirm-metrics/) does the asking).
- `--embedder hash` uses the offline embedder, so nothing is downloaded.
- `--today` fixes the date, so “future dates” and check dates come out the same as here. `--currency` says what the unmarked money columns are in.

## 3. Open the report

The job wrote `agentic-analytics/report.json` and `agentic-analytics/report.html` in the current folder. Open the HTML file in a browser (or add `--open` to the command). Every number in it is followed by a fact ID; click one to see how it was computed.

## What you learned

- One command runs the whole pipeline; the stages print as they go.
- Every number has an ID, and `aa explain` opens its computation.
- The scripted planner makes this reproducible; a real model changes the wording, not the numbers.
