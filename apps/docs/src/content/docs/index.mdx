| **Numbers you can trust** | The model never does arithmetic. DuckDB computes every fact; a verifier recomputes every number before the report ships. |

| **Free and local** | Ollama or a free endpoint, self-hosted SearXNG, in-process embeddings, no telemetry. |
| **Four doors** | CLI, HTTP API, MCP server and a Telegram demo over one engine. |
