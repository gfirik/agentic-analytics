# fixtures

Parser fixtures. Every file is built deterministically by `build.ts` (`bun run --filter @agentic-analytics/fixtures build`). The expected outputs in `*/expected/*.json` are written by hand from each fixture's definition and never generated by the parser under test. Every bug found on a real file becomes a new anonymized fixture here (docs/ENGINEERING.md §5).

| Fixture | What it exercises |
|---|---|
| `xlsx/01-simple` | Plain table with Excel dates |
| `xlsx/02-title-notes` | Title and note above the table, a source note below |
| `xlsx/03-merged-header` | Two-row merged header → `Sales / Revenue`; vertical merge in the header |
| `xlsx/04-two-tables-side` | Two tables side by side, one blank column apart |
| `xlsx/05-stacked-tables` | Two tables stacked, one blank row apart |
| `xlsx/06-totals` | Subtotal by keyword, unlabeled subtotal by sum check, grand total |
| `xlsx/07-transposed` | Months across columns → long format, with a Total column |
| `xlsx/08-hidden-sheet` | Hidden sheet (read, flagged) |
| `xlsx/09-formulas` | Cached formula values; a formula with no cached value |
| `xlsx/10-blank-row-inside` | Spacer row inside one table (not split) |
| `xlsx/11-notes-only-sheet` | A text-only sheet next to a data sheet |
| `xlsx/12-russian` | Cyrillic sheet and headers, `Итого` total |
| `xlsx/13-vertical-merge` | Category cells merged down the body (propagated) |
| `xlsx/14-offset-table` | Table starting at C3 under a title in B1 |
| `xlsx/15-legacy.xls` | BIFF8 `.xls` |
| `xlsx/16-corrupted` | Truncated `.xlsx` → `unreadable_file` |
| `csv/01-semicolon` | BOM, `;` delimiter, quoted delimiter and quotes, decimal commas kept as text |
| `csv/02-tabs.tsv` | Tab-separated |
| `docs/*` | Multi-page PDF, no-text-layer PDF, password-protected PDF, corrupted PDF/DOCX, DOCX with nested headings and a list, EML with a CSV attachment, Markdown, plain text, a ZIP archive |
